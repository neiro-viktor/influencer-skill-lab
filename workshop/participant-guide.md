# Практика: реальный профиль → результат в таблице → свой навык

## Результат за занятие

Вы установите готовый навык, проверите через интернет 1–2 реальных публичных профиля,
получите актуальные метрики со ссылками-доказательствами, вернёте результат в табличный
вид и соберёте свой навык для повторяющейся задачи.

## 1. Установить готовый навык с GitHub

Скопируйте ссылку `https://github.com/neiro-viktor/influencer-skill-lab/tree/main/skills/proverka-blogerov` и напишите Codex обычными словами:

```text
Установи навык «Проверка блогеров» из этой ссылки GitHub. Проверь наличие SKILL.md и покажи папку навыка. Ничего пока не запускай.
```

## 2. Создать личную таблицу и проверить два профиля

Попросите навык открыть шаблон. В Google Sheets нажмите «Создать копию», затем скопируйте адрес личной таблицы обратно в Codex.

```text
Используй навык «Проверка блогеров». Открой мне личную копию учебной Google-таблицы. После того как я пришлю ссылку моей копии, проверь первые два публичных профиля по трём последним роликам и подготовь заполнение H и N:S. Не подставляй демоданные и не записывай ничего без моего подтверждения.
```

Контрольная точка: созданы `live-results.json`, `sheet-write-plan.json`, `for-onegroup-H.tsv` и `for-onegroup-N-S.tsv`. В JSON есть прямые URL реально открытых роликов.

## 3. Вернуть результат в Google Sheets

Если Google-коннектор уже подключён:

```text
Покажи sheet-write-plan.json: мою таблицу, вкладку, строки и диапазоны H и N:S. Ничего не записывай до моего подтверждения. После подтверждения заполни ячейки и перечитай H и N:S для проверки.
```

Если коннектора нет, вставьте `for-onegroup-H.tsv` в H первой проверенной строки, затем `for-onegroup-N-S.tsv` — в N той же строки. API-ключ для этого не нужен.

## 4. Посмотреть главный файл

```text
Открой папку навыка и файл SKILL.md. Объясни в двух предложениях, как навык превращает ссылки на профили в проверяемый результат. Остальные файлы не разбирай построчно.
```

## 5. Собрать свой навык

```text
Используй «Проверку блогеров» как пример. Создай мне навык для повторяющейся работы: ОПИШИТЕ_ЗАДАЧУ. Сначала задай не больше трёх коротких вопросов. Затем собери простую версию, проверь её на безопасном реальном или учебном входе и открой папку с результатом.
```

## План Б

Если площадка временно не отдаёт профиль, Codex должен показать реальную ошибку. После
этого можно отдельно попросить деморежим, чтобы разобрать механику. Демо не выдаётся за
реальную проверку и не заменяет повторный live-прогон.
