# Практика: вся подборка → глубокая проверка контента → заполненная таблица

## Результат за занятие

Вы установите готовый навык прямо с GitHub, проверите через интернет всю подборку
публичных профилей по 10 последним роликам, получите метрики, мат с таймкодами и
цитатами, упоминания конкурентов и подробные комментарии, а затем заполните личную
Google-таблицу и соберёте свой навык по аналогии.

## 1. Установить готовый навык с GitHub

Скопируйте ссылку `https://github.com/neiro-viktor/influencer-skill-lab/tree/main/skills/proverka-blogerov` и напишите Codex обычными словами:

```text
Установи навык «Проверка блогеров» из этой ссылки GitHub. Проверь наличие SKILL.md, scripts/bootstrap_deep.py и slovar.json, покажи папку навыка и скажи, нужен ли перезапуск Codex. Ничего пока не запускай.
```

## 2. Создать личную таблицу и проверить всю подборку

Попросите навык открыть шаблон. В Google Sheets нажмите «Создать копию», затем скопируйте адрес личной таблицы обратно в Codex.

```text
Используй навык «Проверка блогеров». Открой мне личную копию учебной Google-таблицы. После того как я пришлю ссылку моей копии, глубоко проверь все строки: до 10 последних роликов каждого блогера, метрики, мат в речи с таймкодами и цитатами, конкурентов и ролики без расшифровки. Подготовь подробные комментарии и точный план заполнения H и N:S. Не подставляй демоданные, не переключайся на quick-live и ничего не записывай без моего подтверждения.
```

Полный проход может занять заметное время: навык действительно открывает до 10 роликов каждого профиля. Промежуточный результат сохраняется после каждой строки.

Контрольная точка: созданы `результат.json`, `sheet-write-plan.json`, `блок_H.tsv` и `блок_N_S.tsv`. Число записей равно числу обработанных профилей; в контентных находках есть прямые URL, цитаты и таймкоды.

## 3. Вернуть результат в Google Sheets

Если Google-коннектор уже подключён:

```text
Покажи sheet-write-plan.json: мою таблицу, вкладку, число обработанных строк и все диапазоны H и N:S. Покажи один пример комментария с контентным риском. Ничего не записывай до моего подтверждения. После подтверждения заполни все подготовленные ячейки, перечитай H и N:S и выборочно сверь 3–5 строк с планом.
```

Если коннектора нет, вставьте `блок_H.tsv` в H первой проверенной строки, затем `блок_N_S.tsv` — в N той же строки. API-ключ для этого не нужен.

## 4. Посмотреть главный файл

```text
Открой папку навыка и файл SKILL.md. Объясни в двух предложениях, как навык превращает ссылки на профили в проверяемый результат. Остальные файлы не разбирай построчно.
```

## 5. Собрать свой навык

```text
Используй «Проверку блогеров» как пример. Создай мне навык для повторяющейся работы: ОПИШИТЕ_ЗАДАЧУ. Сначала задай не больше трёх коротких вопросов. Затем собери простую версию, проверь её на безопасном реальном или учебном входе и открой папку с результатом.
```

## План Б

Если площадка временно не отдаёт профиль, Codex должен показать реальную ошибку. После
этого можно отдельно попросить деморежим, чтобы разобрать механику. Демо не выдаётся за
реальную проверку и не заменяет повторный live-прогон.
