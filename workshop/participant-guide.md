# Практика: реальный профиль → результат в таблице → свой навык

## Результат за занятие

Вы установите готовый навык, проверите через интернет 1–2 реальных публичных профиля,
получите актуальные метрики со ссылками-доказательствами, вернёте результат в табличный
вид и соберёте свой навык для повторяющейся задачи.

## 1. Установить готовый навык

Скачайте ZIP из релиза, перетащите его в Codex и напишите обычными словами:

```text
Установи навык из этого ZIP. Распакуй, проверь наличие SKILL.md и покажи папку навыка. Ничего пока не запускай.
```

## 2. Проверить реальный профиль

Выберите один открытый TikTok- или YouTube-профиль, который можно проверять по публичным
данным. Для занятия достаточно трёх последних роликов.

```text
Используй навык «Проверка блогеров» и интернет. Проверь этот реальный публичный профиль: ВСТАВЬТЕ_ССЫЛКУ. Сделай быстрый снимок по трём последним роликам: подписчики, просмотры, реакции, выбросы, прогноз и ER. Сохрани время проверки и прямые ссылки на ролики. Не подставляй демоданные, если профиль не откроется. В конце открой папку с результатом.
```

Контрольная точка: созданы `live-results.csv`, `live-results.json`, `live-report.md`
и `for-sheet.tsv`. В JSON есть прямые URL реально открытых роликов.

## 3. Вернуть результат в Google Sheets

Если Google-коннектор уже подключён:

```text
Покажи строки из for-sheet.tsv, которые собираешься записать, и назови таблицу и вкладку. Ничего не записывай до моего подтверждения. После подтверждения внеси строки и перечитай их из таблицы для проверки.
```

Если коннектора нет, откройте `for-sheet.tsv`, скопируйте весь блок и вставьте его в
выданную преподавателем Google-таблицу. API-ключ для этого не нужен.

## 4. Посмотреть главный файл

```text
Открой папку навыка и файл SKILL.md. Объясни в двух предложениях, как навык превращает ссылки на профили в проверяемый результат. Остальные файлы не разбирай построчно.
```

## 5. Собрать свой навык

```text
Используй «Проверку блогеров» как пример. Создай мне навык для повторяющейся работы: ОПИШИТЕ_ЗАДАЧУ. Сначала задай не больше трёх коротких вопросов. Затем собери простую версию, проверь её на безопасном реальном или учебном входе и открой папку с результатом.
```

## План Б

Если площадка временно не отдаёт профиль, Codex должен показать реальную ошибку. После
этого можно отдельно попросить деморежим, чтобы разобрать механику. Демо не выдаётся за
реальную проверку и не заменяет повторный live-прогон.
