# Сценарий преподавателя — 70 минут

## 0–4. Результат и рамка

Показать конечные шесть файлов. Проговорить: сегодня терминал — не тема сам по себе, а среда, в которой команда упаковывает повторяемый рабочий процесс.

## 4–12. Установка из GitHub

Все выполняют один запрос `$skill-installer`. Не переустанавливать Codex. Общая точка готовности: навык виден в `/skills`, известен путь к его папке. Если GitHub недоступен — использовать ZIP из релиза.

## 12–18. Анатомия навыка

Открыть папку и показать пять слоёв: инструкция, интерфейс, скрипт, справка, данные. Не разбирать Python построчно; показать контракт входа и выхода.

## 18–28. Шесть блогеров

Запустить демо. Перед открытием результата спросить прогноз группы по каждому кейсу. Разобрать: чистый профиль, слабый прогноз, конкурент, ненормативная лексика с таймкодом, вирусный выброс, неполные данные.

## 28–34. Таблица и live-ветка

Показать публичный CSV-адрес Google Sheets и четыре вкладки рабочего контура. Live-метрики — только короткая демонстрация преподавателя; при любой нестабильности сразу вернуться к сохранённому демо.

## 34–50. Создание второго навыка

Участники вызывают `$skill-creator`, утверждают план файлов и запускают реализацию. Обязательные ограничения: не выдумывать пропуски, сохранять исходное решение, проверять общий бюджет.

## 50–58. Тест и сравнение

Запустить второй навык. Сверить: два кандидата в шорт-листе; один в резерве; два на ручной проверке; один отклонён. Открыть эталон только после собственного прогона.

## 58–62. Корпоративный мост

Показать формулу: Google Sheets хранит очередь и результат; навык хранит правила; MCP или коннектор даёт контролируемое чтение/запись; человек оставляет финальное решение.

## 62–70. Перенос в работу и анкета

Каждый называет один повторяемый процесс своего отдела и четыре поля: триггер, вход, правила, результат. Затем финальная анкета: https://neiro-viktor.ru/og-final/ — код `digital-2026`.

## План «Б»

- GitHub недоступен → ZIP релиза;
- Python не найден → преподаватель показывает заранее созданные CSV и Markdown;
- Google Sheets закрыт → встроенный `bloggers.csv`;
- внешний профиль не открывается → сохранённые синтетические доказательства;
- участник отстал → работает в паре и начинает со второго навыка после общей демонстрации.
