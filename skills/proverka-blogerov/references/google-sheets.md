# Google Sheets

## Чтение без коннектора

Для публичной таблицы открыть доступ «Все, у кого есть ссылка — читатель» и использовать CSV-адрес:

`https://docs.google.com/spreadsheets/d/SHEET_ID/gviz/tq?tqx=out:csv&sheet=Кандидаты`

Можно передать обычную ссылку на документ: live-скрипт сам преобразует её в CSV.
В quick-live ограничить прогон двумя профилями, чтобы занятие не превратилось в долгую
пакетную обработку. Навык только читает таблицу и не требует токена.

## Практика Onegroup: личная копия

- Шаблон входа: `https://docs.google.com/spreadsheets/d/1DzqwIBC4nvX2VFtv6q2imZGHwpUxgDmg1jDvoAu90_s/copy`.
- Эталон полного результата: `https://docs.google.com/spreadsheets/d/1ycHxx6AZvPIt-rOj60rJQObqSZC8nlKqVu0lmiWmu7c/edit?usp=sharing`.
- Вкладка: `Несогласованные блогеры`; заголовки — строка 3, данные — с строки 4.
- Вход: F — ник, G — ссылка, J — стоимость публикации.
- Заполнение: H — подписчики; N — прогноз просмотров; O — прогноз охвата; P — ER как доля для процентного формата; Q — CPV; R — вердикт; S — комментарий.
- Не перезаписывать формулы L и M, исходные поля B:G и цену J.

Каждый участник сначала нажимает «Создать копию». Проверять ID: документ назначения обязан отличаться от ID шаблона `1DzqwIBC4nvX2VFtv6q2imZGHwpUxgDmg1jDvoAu90_s`. В quick-live обрабатываются первые две строки с открытыми ссылками. Он даёт актуальные метрики и предварительный вердикт, но честно отмечает, что речь, мат, конкуренты и кадры не проверялись. Полное сходство с эталонным комментарием требует глубокого прохода по 10 роликам с анализом речи и изображения.

## Запись через коннектор

Если в текущем клиенте доступен подключённый Google Drive/Sheets, сначала открыть
`sheet-write-plan.json`, показать пользователю личную копию, строки и диапазоны. Записывать
только после явного подтверждения, затем перечитать H и N:S. Рекомендуемые вкладки:

1. `Кандидаты` — исходные строки;
2. `Результат проверки` — поля `screening.csv`;
3. `Шорт-лист` — результат второго навыка;
4. `Реестр пилотов` — ответственный, дата проверки, решение человека.

Если коннектора нет, для соседних строк открыть `for-onegroup-H.tsv` и вставить блок в H первой строки, затем `for-onegroup-N-S.tsv` — в N первой строки. Не просить токен и не имитировать успешную запись.
