# Google Sheets

## Чтение без MCP

Для публичной таблицы открыть доступ «Все, у кого есть ссылка — читатель» и использовать CSV-адрес:

`https://docs.google.com/spreadsheets/d/SHEET_ID/gviz/tq?tqx=out:csv&sheet=Кандидаты`

Передавать этот адрес параметром `--sheet-url`. Навык только читает его и не требует токена.

## Запись через коннектор

Если в текущем клиенте доступен подключённый Google Drive/Sheets, сначала показать пользователю, какие строки и в какую вкладку будут записаны. Записывать только после явного подтверждения. Рекомендуемые вкладки:

1. `Кандидаты` — исходные строки;
2. `Результат проверки` — поля `screening.csv`;
3. `Шорт-лист` — результат второго навыка;
4. `Реестр пилотов` — ответственный, дата проверки, решение человека.

Если коннектора нет, сохранить CSV локально. Не просить токен и не имитировать успешную запись.
