# Контракт данных

## Реальный quick-live

Минимальный CSV содержит `profile_url`. Допустимые дополнительные поля:

`participant,profile_url,price_rub,target_forecast_views`

Ссылка должна вести на открытый профиль TikTok, YouTube или VK. Результат всегда
содержит время снимка и прямые URL роликов-доказательств. Отсутствующая цена не
додумывается: CPV остаётся пустым. Отсутствующая цель не подменяется учебной.

## Воспроизводимое демо

Входной CSV обязан содержать:

`candidate_id,handle,platform,followers,price_rub,campaign,target_forecast_views`

Синтетические доказательства лежат в `assets/evidence.json`. Для каждого `candidate_id` там находятся:

- `videos` — список роликов с `views`, `likes`, `comments`, `shares`;
- `transcript_coverage` — доля проверенной речи от 0 до 1;
- `profanity_hits` — подтверждённые фрагменты с таймкодом;
- `competitor_hits` — подтверждённые упоминания конкурентов.

Расчёты:

- медиана просмотров — по всем доступным роликам;
- выброс — просмотр выше `3 × медиана`;
- среднее — без выбросов;
- прогноз — `среднее × 0,9`;
- прогнозный охват — `прогноз / 1,15`;
- ER — `(средние лайки + комментарии + репосты) / подписчики × 100`;
- CPV — `цена / прогноз просмотров`.

Числа округляются только при записи результата. JSON сохраняет исходные доказательства и вычисленные поля.
