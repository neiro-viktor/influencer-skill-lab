# Опциональный live-режим

Live-режим нужен только преподавателю для демонстрации нестабильности внешних источников.

- Проверить наличие `yt-dlp` командой `yt-dlp --version`.
- Работать только с открытым URL, который передал пользователь.
- Не использовать cookies, обход ограничений или скачивание закрытых данных.
- Считать метрики моментальным снимком, а не неизменной истиной.
- Если ролики или субтитры недоступны, остановить live-ветку и продолжить на сохранённом демо.
