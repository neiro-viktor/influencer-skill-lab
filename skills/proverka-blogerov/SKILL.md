# Проверка блогеров

Сначала определить режим и не смешивать учебные и реальные данные.

## Режимы

1. `demo` — основной и воспроизводимый. Использовать встроенные синтетические данные.
2. `public-sheet` — прочитать CSV по публичной ссылке Google Sheets или локальный CSV. При сетевой ошибке явно перейти на локальный резерв.
3. `live-metrics` — только по явному запросу пользователя и только для метрик открытого профиля. Не обещать расшифровку речи: доступность субтитров и роликов нестабильна.

## Рабочий порядок

1. Прочитать [references/data-contract.md](references/data-contract.md).
2. Для Google Sheets дополнительно прочитать [references/google-sheets.md](references/google-sheets.md).
3. Запустить предварительную проверку:

   ```bash
   python3 scripts/preflight.py
   ```

4. Для деморежима выполнить:

   ```bash
   python3 scripts/demo_screening.py --output output/screening
   ```

5. Для публичной таблицы передать `--sheet-url`. Если URL недоступен, скрипт использует встроенный CSV и зафиксирует это в отчёте:

   ```bash
   python3 scripts/demo_screening.py --sheet-url "URL_CSV" --output output/screening
   ```

6. Проверить, что созданы `screening.csv`, `screening.json` и `report.md`.
7. Сообщить пользователю путь к файлам, число обработанных строк, число выбросов и распределение решений.

## Правила решений

- Не заполнять отсутствующие факты догадками.
- При покрытии расшифровкой ниже 80% или менее пяти роликов ставить «Нужна ручная проверка».
- При упоминании конкурента ставить «Нужна ручная проверка».
- При подтверждённой ненормативной лексике ставить «Не рекомендовать без согласования» и сохранять таймкод.
- Если прогноз ниже 75% целевого, ставить «С оговоркой».
- В остальных случаях ставить «Подходит».
- Исключать из среднего просмотры выше трёх медиан, но обязательно показывать число исключённых выбросов.

## Границы

Результат — первичный скрининг, а не финальное согласование бренда. Для реальной кампании просить человека проверить спорные фрагменты, права на данные, актуальность цены и договорные ограничения.
